# streamline-brand

The Streamline Infotech logo, at a public address so the sign-in pages can load it.

- `streamline-logo.svg`: the wordmark, orange `#f7931e`.

Served at `https://girishzalke.github.io/streamline-brand/streamline-logo.svg`. The sign-in pages point at this file, so do not rename or move it without changing `branding.logo_url` in `streamline-signin` first.
